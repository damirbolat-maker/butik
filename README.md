# Мой бутик

Учёт товаров, продаж, клиентов, долгов, партий и расходов для перепродажи одежды и аксессуаров.

- Приложение: https://damirbolat-maker.github.io/butik/
- Витрина для клиентов: https://damirbolat-maker.github.io/butik/catalog.html

Данные хранятся в Supabase (проект `butik`), доступ только по логину.
